# VR Version Foundation

The future VR version lives at `vr/index.html` for now.

This first version intentionally looks like the current 2D site rather than entering WebXR. It exists as a separate destination so VR-specific UI and rendering can be developed without destabilizing the established main page.

The page loads the same shared world-state model and includes the `D` debug button. Future phases can add an `Enter VR` control and WebXR session setup here.
