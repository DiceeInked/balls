# Project Reference

This folder contains reference copies of the current VR design summary and implementation steps.

The files here are reference material, not the authoritative rule set. The active skills directly inside `Skills/` remain the living specification.

When a project change is made:
1. Read every active skill in `Skills/`.
2. Use these reference documents for broader context and implementation history.
3. Follow the newest explicit project rule if it conflicts with older reference text.
4. Update affected active skills when the project rules change.

Reference documents:
- `mechanics-summary.md` - consolidated description of how the VR system works.
- `implementation-steps.md` - staged plan for building the VR system.
